# QA 檢查清單

先跑 `npm run build`，確認 `tsc` 和 build 都沒有錯誤，再用 `npm run dev` 逐項檢查。截圖前要先顯示 Browser pane。

## 畫面（3 個角度 × 4 種樣式）

- [ ] `?yaw=-4&pitch=8`：山頂是剪影最高點，倒影完整（看得到山頂倒影），湖岸沒有鋸齒。
- [ ] `?yaw=20&pitch=40&fov=85`：看得到銀河與暗帶；輻射點附近的流星比較短。
- [ ] `?pitch=-15&fov=60`：湖面看得到星星倒影，波紋不誇張。
- [ ] `?preset=moonlight`、`aurora`、`bluehour` 各截一張，雪面不能死白，天空不能全黑。

## 天文正確性

- [ ] 8/13 01:30：北極星約在方位 1°、仰角 47°；北斗的天樞約在方位 351°、仰角 20°（就在山頂上方）；天津四接近天頂。
- [ ] 「看輻射點」轉到東北方，仰角約 43°。

## 流星

- [ ] 「示範」密度下，30 秒內一定看得到流星，湖裡也看得到流星的倒影。
- [ ] 「來一顆火流星」：帶綠色或橘色，有短暫餘跡；連按 10 次也不能讓畫面變黑（NaN 檢查）。
- [ ] 流星方向是從輻射點往外。

## 星座與認星

- [ ] 預設（第一次開啟、或清掉 localStorage）星座是「不顯示」。
- [ ] `?con=names&yaw=-12&pitch=22&fov=50`：北斗七星的連線端點正好落在星上，斗口在山頂正上方、斗柄往左延伸。
- [ ] `?con=names&yaw=45&pitch=50&fov=60`：仙后座 W 在東北方高空、銀河裡。
- [ ] `?con=names&yaw=-110&pitch=58&fov=85`：夏季大三角（織女星、天津四、牛郎星）各自落在連線上；天津四接近頭頂。
- [ ] 連線又細又淡，看起來比亮星暗；湖面倒影裡**沒有**連線和名稱；地平線附近的連線淡出，山後面的名稱不顯示。
- [ ] 點織女星：卡片標題「織女星（織女一）」，副標「Vega · 夏季大三角」，拜耳名 α Lyr、星座 天琴座、星等 0.03，有介紹文字；星上出現選取圈，轉頭時圈跟著星走。
- [ ] 也可以用 `?star=91262` 直接選織女星截圖。另外抽點牛郎星、天津四、北極星，介紹都在；點一顆沒有介紹的星，卡片只顯示基本資料、名字是繁體。
- [ ] 從星星上開始拖曳轉頭：**不會**選到星；點天空空白處或地景：卡片關閉。
- [ ] 375 px：卡片在左下、不擋設定按鈕；打開面板時面板壓在卡片上方；星座三個選項一行放得下。
- [ ] 星座設定重新整理後保留；4 種星空樣式都開著星座看一次（藍色時刻天空亮，連線仍不刺眼）。

## 介面與存檔

- [ ] 介面閒置 3 秒後淡出；設定按鈕仍可點，點一下就打開面板。
- [ ] 切換樣式、密度、時間、湖面，重新整理後設定仍保留。
- [ ] 在 console 執行 `localStorage.setItem('starshowing_settings_v1','{壞資料')` 後重新整理，不會出錯，並回到預設值。
- [ ] 375 px 寬（Browser pane 的 mobile preset）：沒有水平捲動，面板放得下，按鈕點得到。
- [ ] console 沒有錯誤或 WebGL 警告。
